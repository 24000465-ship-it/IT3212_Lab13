LAB 1 - LAM QUEN VISUAL STUDIO VA LAP TRINH CONSOLE (IT3212)
=============================================================

1. Cach chay
   - Mo IT3212_Labs.sln bang Visual Studio 2022.
   - Build > Rebuild Solution, sau do nhan Ctrl+F5 (hoac F5 de debug).
   - Hoac chay truc tiep: Lab01_Console\bin\Debug\Lab01_Console.exe
   - Tai menu chinh, nhap so 1..10 de chay bai tuong ung. Chay xong moi bai
     chuong trinh quay lai menu chinh.
   - Luu y: may dat dinh dang Viet Nam thi so thap phan nhap bang dau phay (vd: 9,5).
